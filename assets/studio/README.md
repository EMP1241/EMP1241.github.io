The October 22 gallery replaces retired Research Architect GUI concepts with the approved brand-and-real-products direction.

- Identity: the existing PhalAInx emblem from the branded introduction, with founder and studio identity text.
- Products: current RA/HC icons, the public RA white-paper cover, and an existing capture of the working HC Command Deck. RA is identified as a development preview and HC as active alpha testing.
