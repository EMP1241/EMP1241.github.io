# PhalAInx studio gallery

The October 22 gallery replaces retired Research Architect GUI concepts with the approved brand-and-real-products direction.

- Identity: the existing PhalAInx emblem from the branded introduction, with founder and studio identity text.
- Products: current RA/HC icons, the public RA white-paper cover, and an existing capture of the working HC Command Deck. RA is identified as a development preview and HC as active alpha testing.
- Development material: the actual public white-paper cover, an excerpt of the public synthetic integrity example, and the five successful self-check messages from running that example. The example is portfolio demonstration code, not private RA runtime code.

`tools/build_studio_gallery.py` produces self-contained SVGs from these existing public assets. The cover was rendered on October 25 from the current supplied Research Architect White Paper. The label uses the paper's name, without an edition or page count. These are designed gallery compositions, not application screenshots.
