Checks tied to this distribution

The retained final-package receipt reports consistent installed runtime files, startup routing, selected-source reconstruction, and explicit context reuse for all three generated roles. Packaging used the extracted revision-2 archive. Five focused follow-up checks cover failed-operation replay, request-only unknown outcomes, UTF-8 output budgets, repeat/refresh behavior, and timeout handling.

Earlier source-pinned evidence supports unchanged behavior. The 171-test RA 2.1 baseline was retained with 278 matching source pins; these were not counted as 171 newly rerun revision-2 tests. A synthetic Library registration, replay, and correction was discoverable by a second generated kit. This was a local integration check, distinct from production publication or participant rollout.

What the context measurement means

A repeated-context fixture emitted 119,362 prompt characters instead of 773,391, an 84.5664% reduction, while retaining matching selected-source hashes and full reconstruction. Confirmed reuse emitted 277 characters. The comparison measures repeated text in a defined fixture; it is not a provider-token or billing percentage, and it is not a universal reduction for all projects.

Remaining scope

The broader fresh live-agent research and coordination evaluation remains open. Fresh Python processes check runtime restoration, not new model conversations or proof that an assistant read the restored text. Existing successful pilot operations remain evidence for their recorded scenarios. This package did not automatically upgrade live NWSW kits, grant remote access, or establish scientific validity.
