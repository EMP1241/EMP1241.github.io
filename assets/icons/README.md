# Application artwork

These icons are taken from Brandon Santor's existing application assets. The artwork has not been redrawn or cropped.

- `trae.png`: Largest PNG-compatible frame of the TRAE application icon.
- `tvae.png`: TVAE launcher's existing 256-pixel icon.
- `phalainx.png`: Largest frame of the current PhalAInx Windows application icon, used for the Research Architect project at the owner's request.

ICO frames were exported as PNG without resizing. PNG metadata was omitted. Original project assets remain unchanged.
