# PhalAInx introduction clip

`phalainx-introduction.mp4` is the original 10-second branded startup animation from the project's current branding source, `phalainx-splash-video.mp4`. The source branding documentation identifies older archived clips as superseded.

The public file preserves the original H.264 video and AAC audio streams, removes container metadata, and moves the MP4 index forward for web playback. Legacy PhalAInx links containing `?intro=1` start the clip muted in a skippable native dialog; current links from HC and RA open the unlisted studio page directly, with manual replay available. Native controls provide sound and playback; the clip closes on completion. Direct page visits and reduced-motion preferences retain manual playback, with replay available. Failed playback leaves a path to the studio. This is a generated brand animation, separate from the application screenshots and provider integration work.

The visible clip frames were reviewed for private contact details and local paths. Audio was not independently transcribed or reviewed.

## Research application demonstrations — October 22, 2026

Three genuine browser-tab recordings show the running applications. Each public clip is 14 seconds, silent, encoded as H.264/YUV 4:2:0 at 1440 × 900 with a 30 fps output timeline and progressive playback. Posters are extracted from the clips. Capture padding was cropped from TRAE; TVAE and Mars were resized proportionally. Application interactions and imagery were not fabricated. Application chrome, source labels, and visible map attribution remain in the recordings. The homepage and each corresponding project gallery use these same files.

- `trae-demo-20261022.mp4`: TRAE v1.0.0, using temporary imports of the public NOAA/NCEI Fish Creek Trail files `ca609.rwl` and `ca609.crn`. The year window changes to 1850–1995 and returns to the full record. The minimap is collapsed. The displayed raw-width site mean is not presented as a validated chronology or a climate result.
- `tvae-demo-20261022.mp4`: TVAE v1.3.0, showing the source-backed Kairei Field vent record, GEBCO seafloor context, and Bird (2003) PB2002 tectonic plate boundaries. The demo uses an isolated local browser session without the write-back sidecar or imported user data. Brief tile loading during zoom is part of the running application.
- `mars-demo-20261022.mp4`: Mars Explorer v0.9.1 from an isolated portable demonstration copy. The Mont Mercou location map opens into its interactive sol 3049 Navcam panoramic viewer and pans across the imagery. NASA/JPL-Caltech is the image source; its mosaic seams and gaps remain visible. This panoramic viewer is separate from the orbital-data 3D terrain reconstruction.

The clips contain only application content, with no audio, desktop windows, phone numbers, street addresses, credentials, or private project files. Frame contact sheets were reviewed before publication. Gallery playback respects reduced motion and the site-wide Pause effects control; native video controls and enlarged playback remain available.
