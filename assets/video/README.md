# PhalAInx introduction clip

`phalainx-introduction.mp4` is the original 10-second branded startup animation from the project's current branding source, `phalainx-splash-video.mp4`. The source branding documentation identifies older archived clips as superseded.

The public file preserves the original H.264 video and AAC audio streams, removes container metadata, and moves the MP4 index forward for web playback. Opening the PhalAInx project through portfolio links starts the clip muted in a skippable native dialog. Native controls provide sound and playback; the clip closes on completion. Direct page visits and reduced-motion preferences retain manual playback, with replay available. Failed playback leaves a path to the project. This is a generated brand animation, separate from the application screenshots and provider integration work.

The visible clip frames were reviewed for private contact details and local paths. Audio was not independently transcribed or reviewed.
