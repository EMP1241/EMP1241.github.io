# Brandon Santor · Geospatial Research & Software

Static personal portfolio with ten case studies: New World Screwworm research, the independent Spatial Evidence Workbench, Mars Explorer, COLE, Tree-Ring Atlas Explorer, Thermal Vent Atlas Explorer, Research Architect, smartphone GNSS research, High Command, and the NASA SUITS student proposal. An unlisted PhalAInx studio page is linked from Research Architect and High Command. PhalAInx is Brandon's independent software studio. Research Architect is a human-team research framework; High Command is a personal multi-model application in alpha testing.

Open `index.html` in a modern browser or serve the repository root with a static HTTP server. No build or package installation is required.

- `index.html` features the New World Screwworm project and its broader research, GIS, and evidence-integration work.
- `about.html`, `projects.html`, and `resume.html` provide the main sections.
- Ten listed case studies and the unlisted studio page each have a three-item gallery. High Command has two screenshots and a five-second Home-screen recording. The unlisted studio uses “Studio at a glance.” Native disclosures work without JavaScript. Detailed verification records are optional expansions; demos remain visible.

PDF links open a separate tab.
- `site.js` provides the saved theme preference, legacy fragment redirects, and résumé print control.
- `gallery.js` provides seven-second image rotation and end-of-video advancement, a per-gallery pause/resume control, and a keyboard-accessible native-dialog image/video viewer with image fit/full-resolution controls, native video controls, loading/error feedback, and focus restoration. Image rotation pauses on hover; both media types pause rotation for keyboard focus, lightbox viewing, hidden/off-screen pages, and the global effects control. Reduced-motion users retain manual navigation and playback. Video completion advances after a short pause; a fallback handles unavailable or stalled previews. Mouse, touch, or playback-key interaction stops rotation and gives the visitor control of that video; later visibility changes do not restart or mute it. Captions expand to fit their text, with the tallest slide reserving space so controls stay in place.

Each project header has a labeled tools-and-methods tag list; Research Architect and High Command have separate project entries and credit PhalAInx as the independent studio. Optional PNG previews and text-width checks support visual review.
- `motion.js` provides bounded parallax, rotating hero highlights, one-time scroll reveals, and the persistent pause control. The CSS adds slow ambient motion to every hero banner. Effects respect reduced-motion preferences, pause while the page is hidden, and pause on request.
- `assets/icons/` contains original TRAE, TVAE, PhalAInx, and author-supplied Research Architect artwork. COLE uses its current application icon; Mars uses an interface-derived mark.
- `assets/screenshots/` contains reviewed application captures and author-supplied research figures. Its README records provenance and limitations.
- `assets/video/` contains the original PhalAInx branded introduction, a five-second native Windows HC Home recording, and under-10-second edited working-app demonstrations for Mars Explorer, TRAE, and TVAE, with their provenance.
- `assets/tamu-white.svg` is the official white university mark used in the header.

Dark mode is the default. Theme and optional effects preferences are saved locally in the visitor’s browser. Core navigation, case-study content, image links, and native video playback work without JavaScript. Image galleries auto-advance only while visible and unattended, with a soft fade and an explicit pause control. Automatic position changes do not generate live screen-reader announcements. Current product-page studio links open the studio directly, with manual introduction replay. Legacy studio links containing `?intro=1` still start its 10-second clip muted in a native dialog and reveal the studio when it ends or is skipped. The query is consumed so a refresh does not repeat it. Direct visits retain manual playback and replay. Reduced-motion visitors get manual Play; failed autoplay keeps controls and Skip available. Playback pauses when the page becomes hidden. Old home-page fragments redirect to corresponding pages.
