A geographic workspace for the deep ocean

Hydrothermal-vent records become more useful when researchers can see their relationship to ocean basins, mid-ocean ridges, and neighboring sites. TVAE combines those records with bathymetry and plate boundaries, with local overview maps for use without an internet connection.

My role

I independently designed and developed TVAE from Sylvan Lab requirements, built its online and offline mapping workflows, and delivered it to the lab for review and internal use.

I developed imports, filtering, site inspection, measurement, comparisons, analytical summaries, saved sessions, and provenance-rich exports. Companion features extend the application from an atlas into a practical research workspace.

Seafloor context at the right scale

The source layer preserves 721 vent-field records from InterRidge v3.4. The local CSV also contains twenty added vent/subsite records and one test/example row; these additions are not InterRidge observations. GEBCO 2025 supplies seafloor relief and PB2002 supplies tectonic plate boundaries. The gallery shows a public source vent in its wider ocean setting.

From vents to geomicrobiology

Geomicrobiology studies how microbes interact with geology and chemistry. Core vent fields, local biological enrichments, and imported overlays have separate field sets and export controls. Local measurements and genomic context require their own sources; genomic potential does not demonstrate measured biological activity. Base-file membership alone is not proof of an InterRidge origin.

Feature add-ons for research questions

Nearby-site tools and side-by-side comparisons help inspect two to twelve selected vents. Activity and depth summaries, exploratory plots, annotations, and a cruise waypoint planner help researchers organize questions and locations. An optional Python helper samples bathymetry from NetCDF or GMT scientific data files; the resulting values remain tied to their input sources.

CSV and point GeoJSON imports retain custom fields and receive their own import review. Exports follow an explicit selected, filtered, or complete scope, with separate field sets for core records, enrichments, and imported data.

The Windows and macOS portable 1.3.0 archives match the checked frontend, base CSV, helper sources, and platform startup scripts. That is source-payload parity, not a new installed-runtime qualification. The current atlas includes local additions and an example row, so source records need to be distinguished when interpreting a scientific view.

A workspace that can travel

Local GEBCO overview tiles and hillshade keep a broad seafloor map available offline. The local tiles are native through zoom level 5; closer views enlarge the available tiles rather than adding finer source data. A saved session remembers filters, selected vents, imported rows, notes, route points, and map view, but it does not duplicate the full atlas. When connected, Esri ocean layers support closer inspection. An optional local Python service can write atlas edits to the base CSV and save a backup. Browser imports stay separate unless a user explicitly exports them or includes them in a session.
