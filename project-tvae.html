Online & offline exploration

The problem

Hydrothermal-vent research needed an interactive way to review records while retaining map access during cruises and remote fieldwork without internet.

My role, data & method

I independently developed the WebGIS from Sylvan Lab requirements. I built online and offline map modes, spreadsheet/CSV and GeoJSON imports, filtering, measurement, saved analytical state, and exports that preserve provenance.

What I found

I delivered TVAE to Sylvan Lab. Dr. Jason B. Sylvan uses it for education and lab research in field and classroom settings.

Exploring the atlas

A researcher can search by vent name and descriptive fields, browse atlas regions, filter dates, and select records for mapped inspection. The selected record’s details sit beside the map. Nearby-site tools, comparisons, activity and depth summaries, annotations, and exploratory plots help organize questions about the loaded atlas.

Source data and local context

The base atlas credits the InterRidge Global Database of Active Submarine Hydrothermal Vent Fields v3.4. The interface distinguishes core source fields from local TVAE enrichments and imported user rows. A provenance panel identifies the record source, citation, and field groups, while a field dictionary explains how columns should be interpreted.

Research files and reusable sessions

CSV and point GeoJSON imports are reviewed as separate user data rather than silently merged with authoritative vent records. Exports use the selected, filtered, or complete record scope, with options for core fields, local enrichments, or imported data. Session files retain filters, selections, imported rows, annotations, route, map position, and layer settings; they depend on the matching base atlas rather than embedding a complete base-data copy.

Offline use and planning

The Leaflet interface uses locally served GEBCO overview tiles and hillshade. Online mode can use streamed imagery at closer zooms; the current bundled offline range is scaled beyond its native levels. A cruise planner records waypoints and leg distances for exploration, and an optional local sidecar supports persistent atlas edits. Route tools are for research planning rather than operational navigation.
